🛡️ Security & Server Actions Difficulties

1. Duplicate JSON Keys in i18n next-intl

The Problem
VS Code reported "Duplicate object key" errors in en.json and ar.json. The original template already had a "Checkout" block, and we added a second one, causing JSON parsers to overwrite the first.
The Solution
Manually inspected the JSON files and removed the old, unused "Checkout" block, merging all keys into a single object.

2. Security: Never Trust Client Prices Zod Prisma

The Problem
A malicious user could modify the Zustand cart in their browser to change a product's price to $0.01 before submitting the order.
The Solution
The createOrder Server Action ignores client prices. It takes only the productId, variantId, and quantity, then re-fetches the real price from the database to calculate the total securely.
⚛️ React 19 & UI Fixes

3. Duplicate Hook Imports & Declarations React 19

The Problem
During refactoring to use useSyncExternalStore, duplicate imports and variable declarations caused TypeScript errors in CheckoutForm.tsx.
The Solution
Replaced the entire file cleanly, ensuring only one import statement and one declaration per hook exists at the top of the component.

4. Missing Cart Link to Checkout Next.js

The Problem
Clicking "Proceed to Checkout" did nothing because the button in CartClient.tsx was a static HTML <button> instead of a Next.js <Link>.
The Solution
Replaced the button with a <Link href="/checkout"> component, adding block and text-center classes to preserve the button styling.
🧠 Developer Cheat-Sheet & Pro-Tips
  • Server Actions Security: NEVER trust prices or totals sent from the client. Always re-fetch product prices from the database inside the Server Action and recalculate the total before saving the order.
  • React 19 Form Submission: Use useActionState to handle the Server Action response (errors, success states) and isPending to disable the submit button while the network request is in flight.
  • Passing Complex Data to Server Actions: Server Actions accept FormData. To pass the cart array, use a hidden input: <input type="hidden" name="items" value={JSON.stringify(cartPayload)} />, then parse it on the server.
  • Zod Schema Validation: Always validate the incoming FormData using zod.safeParse() inside the Server Action before touching the database.
  • JSON Duplicate Keys: VS Code will warn you about duplicate object keys. JSON parsers silently use the last one. Always merge or remove duplicates.

🗄️ Database & Prisma Difficulties

1. Prisma TLS Connection Error (P1011) Prisma 7

The Problem
Querying the database threw Error opening a TLS connection: self-signed certificate in certificate chain. Supabase's connection pooler uses a certificate chain that Node.js/Prisma 7 does not trust by default.
The Solution
Appended ?pgbouncer=true&sslmode=no-verify to the DATABASE_URL in the .env file. This bypasses strict TLS verification, which is safe for development environments.

2. Prisma 7 Seed Configuration Moved Prisma 7

The Problem
Running npx prisma db seed threw ⚠️ No seed command configured. Adding the seed script to package.json (the Prisma 6 method) was ignored.
The Solution
Prisma 7 moved configuration into prisma.config.ts. The seed command must be defined inside the migrations block. 
// prisma.config.ts
export default defineConfig({
  schema: "prisma/schema.prisma",
  migrations: {
    seed: "tsx prisma/seed.ts", // Required for Prisma 7
  },
  // ...
});

3. Prisma Schema Relation Mismatch TypeScript

The Problem
The query threw Property 'length' does not exist on type 'never'. We used modifierGroups in the query, but the Prisma schema named the relation modifiers.
The Solution
Always verify the exact relation names in schema.prisma. Changed modifierGroups to modifiers in the include block.
⚛️ Next.js & React Difficulties

4. Navbar Hydration Mismatch Next.js 16

The Problem
The browser threw a hydration error: href="/en/menu" (client) did not match href="/en/shop" (server). The Navbar (Client Component) was reading storeConfig.businessType directly, which evaluated differently on the server vs. client bundle.
The Solution
Passed businessType from the Server Layout (layout.tsx) down to the Client Navbar as a prop. This guarantees the server and client render the exact same HTML tree.

5. Next.js Image Performance Warnings Next.js

The Problem
The console threw warnings about Largest Contentful Paint (LCP) and missing sizes props for images using fill.
The Solution
Added priority={index < 4} to the first 4 product cards (above the fold) in the Shop Page. Added sizes="96px" to the cart thumbnail image.
🧠 Developer Cheat-Sheet & Pro-Tips
  • Serialization Boundary: Never pass Prisma Decimal objects directly to Client Components. Always call .toString() on the server (inside the query) and handle the conversion on the client.
  • Server-Only Queries: Always add import "server-only"; at the top of files containing Prisma queries. Next.js will throw a build error if a Client Component accidentally imports it, preventing database credentials from leaking.
  • Supabase Connection Strings: For Prisma 7 + Supabase in development, always append ?pgbouncer=true&sslmode=no-verify to avoid the P1011 TLS error.
  • Prisma 7 Seeding: The package.json seed config is dead. Use prisma.config.ts with migrations: { seed: "tsx prisma/seed.ts" }.
  • Next.js Hydration Fix: If a Client Component uses a global config (like storeConfig), pass it as a prop from the Server Layout. Do not import it directly in the Client Component.
  • Image Optimization (LCP): Any next/image that appears on the initial viewport (above the fold) should have the priority prop to improve Core Web Vitals.
  • VS Code False Errors: If you create a new file and VS Code says Cannot find module but the app runs fine, press Ctrl+Shift+P and run TypeScript: Restart TS Server.

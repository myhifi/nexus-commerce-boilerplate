🏗️ Difficulties & Fixes

1. Security Flaw: Self-Deletion NextAuth

The Problem
The user could delete their own admin account, breaking the system. The code checked session.user.id === id, but it always evaluated to false because NextAuth's default JWT session does not include the user ID.
The Solution
Added custom jwt and session callbacks to auth.ts to explicitly pass the user.id into the session token.

2. Form Reset on Validation Error React 19

The Problem
React 19's <form action={formAction}> resets all input fields when the Server Action completes. If validation failed, the user had to retype everything.
The Solution
Updated the UserActionState to return a fields object. The UserForm uses defaultValue={state.fields?.name || user?.name} to preserve the user's input.

3. Hardcoded Sidebar Active State Next.js

The Problem
The Admin Sidebar always highlighted "Orders" because the active class was hardcoded in the layout. Navigating to "Staff" or "Products" left the wrong link highlighted.
The Solution
Extracted the navigation links into a "use client" component (SidebarLinks.tsx) and used the usePathname hook to dynamically apply the bg-accent/10 text-accent classes based on the current URL.

🧠 Developer Cheat-Sheet & Pro-Tips
  • NextAuth Session ID: By default, session.user.id is undefined. You must use the jwt and session callbacks in auth.ts to transfer the ID from the database user to the JWT token, and then to the session object.
  • Preserving Form State: When using Server Actions with validation, always return the submitted data in the state so the Client Component can set the defaultValue of the inputs.
  • Prisma Update Payload: When conditionally updating a password, build a strongly typed object (e.g., UserUpdatePayload) instead of using any. This satisfies ESLint and catches typos.
  • Dynamic Sidebar Highlighting: To keep your layout.tsx as a fast Server Component, extract only the navigation links into a Client Component. Use pathname.startsWith(link.href) to ensure nested routes (like /admin/users/new) still highlight the "Staff" tab.

🧠 Developer Cheat-Sheet & Pro-Tips
  • CSS Bar Charts: Avoid heavy libraries like Chart.js or Recharts for simple dashboards. You can easily build a responsive bar chart using flexbox and dynamic percentage heights (style={{ height: `${(val / max) * 100}%` }}).
  • Prisma GroupBy: To find the best-selling products, use prisma.orderItem.groupBy with _sum: { quantity: true } and order descending. This is highly efficient and avoids pulling all order items into memory.
  • Data accuracy: Always ensure aggregate queries (like revenue) filter by status: "PAID". Otherwise, abandoned or pending orders will inflate your revenue numbers.

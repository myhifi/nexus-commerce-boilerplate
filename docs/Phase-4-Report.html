🗄️ Database & Supabase Difficulties

1. Supabase Project Paused (ENOTFOUND) Supabase

The Problem
The app threw (ENOTFOUND) tenant/user postgres.[REF] not found. The Supabase connection pooler couldn't find the project.
Root Cause
Free-tier Supabase projects automatically pause after a period of inactivity. When paused, the pooler removes the route to the tenant.
The Solution
Logged into the Supabase Dashboard, clicked "Restore project", and waited for the status to change to "Healthy." Then re-ran npx prisma db seed.
⚛️ React & Refactoring

2. Removing `useMemo` for React Compiler React 19

The Problem
ProductDetail.tsx used useMemo for the selectedModifiersFlat array, which violates the project rule of relying on React Compiler.
The Solution
Replaced the useMemo block with a standard synchronous variable assignment. React Compiler handles the memoization automatically under the hood.

3. Prisma Relation Mapping Prisma

The Problem
The Prisma schema names the relation modifiers, but the ProductDetailData type expects the prop name modifierGroups.
The Solution
Mapped the data explicitly in queries.ts: modifierGroups: product.modifiers.map(...). This decouples the DB schema from the UI component's prop shape.
🧠 Developer Cheat-Sheet & Pro-Tips
  • Supabase Free Tier: Projects pause after ~7 days of inactivity. If you get an ENOTFOUND or XX000 error, check the Supabase dashboard first before debugging your code.
  • Dynamic Routes in Next.js 16: The params prop is a Promise. Always await params before accessing properties like slug.
  • SEO for E-commerce: Always use generateMetadata in dynamic routes to set the product title, description, and OpenGraph image.
  • Handling 404s: Use Next.js's notFound() function inside dynamic routes when a database query returns null. It renders the closest not-found.tsx and returns the correct 404 HTTP status.
  • Decoupling DB from UI: Never pass raw Prisma models directly to client components. Always map them to a specific DTO (Data Transfer Object) that perfectly matches the component's props.
